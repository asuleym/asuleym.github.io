# asuleym.github.io

Personal website of Arzu Suleymanova: https://asuleym.github.io

## Files
- index.html: the whole website
- profile.jpg: the photo in the About section
- cv.pdf: the CV that opens from the CV button

## Optional extras
Put these in a folder called `photos`:
- `photos/log-01.jpg` to `photos/log-18.jpg`: the 18 photos in the Photographs section. Each one has a drawing behind it. To swap a photo, upload a new file with the same name.

And next to index.html:
- `portrait.mp4`: a short silent video that replaces the photo in the About section.
