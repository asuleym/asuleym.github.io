# asuleym.github.io

Personal website of Arzu Suleymanova: https://asuleym.github.io

## Files
- index.html: the whole website
- profile.jpg: the photo in the About section
- cv.pdf: the CV that opens from the CV links
- log-01.jpg to log-18.jpg: the 18 photos in the Photographs section. They sit next to index.html, not in a folder. Each one has a drawing behind it. To swap a photo, upload a new file with the same name.

## Optional extra
Next to index.html:
- portrait.mp4: a short silent video that replaces the photo in the About section.
